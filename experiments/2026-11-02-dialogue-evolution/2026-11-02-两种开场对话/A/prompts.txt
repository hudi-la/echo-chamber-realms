# Echo Chamber Realms 提示词总表
#
# 脑子目前有 2 种模型生成，不是每句话都生成两次：
#
# 1. 写台词 compose：程序选中一个角色后，调用 1 次。
#    system prompt：persona_template（填入该角色的 identity、history、strategy、environment）
#                   + belief_heading + 该角色运行记忆中的当前信念。
#    另外的 prompt：recent_heading + 最近现场记录 + compose + performance。
#    同一次生成返回 text，以及 performance 里的 target（对谁说）、tone（语气）；不生成 body。
#    身体动作由程序控制：音频播放时持续动作，句间暂停、打断或结束时停止；不额外调用模型。
#
# 2. 反刍 ruminate：累计对话、访客离开或关机整理等条件触发时，给相应角色调用。
#    system prompt：和写台词相同。
#    另外的 prompt：experience_heading + 待处理的实际对话
#                  + context_heading + daily / end / bedtime（三选一）
#                  + ruminate（其中填入 impression 或 no_impression，以及信念容量 capacity）。
#
# 如果启用声音，还会调用 TTS：声音要求用 voices.<名字>，输入是已经生成的台词。
# decide：现在没有在用。initial_beliefs：只用来初始化记忆，不单独调用模型。
# trial.history / trial.a_boundary：仅 A/B 试验使用；trial.questions：仅旧固定问答测试使用。
#
# zh / en 分别是中英文版本。修改分区正文，保留 [分区名] 和 {占位符}，保存后重启生效。
# 本段说明不会发给模型。

这一步只决定是否开口，不写台词。

[zh.compose]
你获得了本次发言权。
根据你的背景、当前信念和现场，写出你现在说出口的话。
程序已选中你发言；这一步只负责写台词，不再决定是否开口。必须给出至少一句简短、自然、符合你自己的可朗读台词。即使想安静，也用一句话表达，不返回空字符串、纯标点或只有动作描述。
按 performance 分区的要求，只返回包含 text（实际台词）和 performance（target、tone）的 JSON。

[zh.ruminate]
回顾这些经历，完成以下记录。
1. 当前信念：这些经历是否让你形成新的信念，或改变原有信念？是否改变、什么事情对你有分量，由你根据自身背景判断。没有变化就留空，不必为了完成任务而改变。每处变化写明对应的经历和理由。区分亲身经历、别人说的话和自己的推测；不要把别人的说法直接写成已证实的事实。
这些是记录，不是说给别人听的台词。用简短、清楚的文字表达。
返回 JSON：只包含 changes 数组。信念修改用 kind="belief"，who 留空，old 为被修改信念原句（新增留空），new 为新信念，because 为经历和理由。没有记录时 changes 留空。不生成同伴看法或访客印象。
当前信念最多 {capacity} 条；达到上限时修改已有信念，不额外新增。

[zh.personas.Charlie.initial_beliefs]

- 忠诚能换来照顾和位置。

[zh.personas.Lucy.identity]

[zh.personas.Kaka.identity]

[zh.personas.Kaka.history]

[zh.personas.Kaka.environment]

[zh.voices.Kaka]
用普通话朗读输入台词。夸张的卡通鸟类男声，中高音区，尖亮、带一点鼻腔共鸣和俏皮的沙哑边缘；避免低沉稳重、播音腔或成熟绅士感。节奏灵巧跳跃，短促弹跳的重音，音高起伏大，句尾偶尔俏皮上扬，带得意又淘气的笑意。清楚说出每个字，声音有弹性，不要一直尖叫。只演绎原台词，不额外添加笑声、口头禅、叫声或新内容。

[zh.voices.Charlie]
用普通话朗读输入台词。卡通化、甜腻发嗲的女声气质：偏高且圆润，假甜的微笑音，带一点鼻音和故作亲切的娇柔感；像热情过头、爱撒娇又有点控制欲的阿姨。轻柔黏连地起句，关键字夸张上扬，句尾稍稍拖长再收住，讽刺时仍保持甜甜的礼貌。保持清楚和活泼，不要低沉硬朗，不要机械平读。只读输入台词，不添加称呼、笑声或新词。

[zh.voices.Lucy]
用普通话朗读输入台词。非常纤细、柔和、温温软软的卡通少女声；小巧的共鸣、轻盈的高音、带一丝气息和羞怯的温柔感，像小小声认真对人说话。音量要足够清楚，字尾轻轻落下，停顿自然细小，情绪有细微变化。不要耳语、尖叫、过度奶声或逐字拖慢；不要机械平淡。只读输入台词，不加入括号提示、笑声或新内容。

[trial.history]

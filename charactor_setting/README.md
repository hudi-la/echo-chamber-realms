# charactor_setting —— 人设

哪套在用由 `config.toml` 的 `[persona] dir` 决定。**现在用的是 `v2/`**（2026-09-26 起）。

| 位置 | 是什么 | 用不用 |
|---|---|---|
| `Charlie.txt` `Kaka.txt` `Lucy.txt`（本目录） | **原版**人设（2024），一段到底 | 不用（`dir = "charactor_setting"` 可切回） |
| `all.txt` | 原版里一段给三只共用的提示；老代码也没真用上 | 不用 |
| `v2/*.txt` | 按"想法 / 感受 / 策略"重写（去掉了"诗人""艺术家"）。段落顺序就是权重：第一段是模型演的主角 | **用** |
| `v2/seeds.json` | 三只的出厂信念和初始关系，从 v2 生成、作者审定。`--seed` 优先用它 | **用** |

规矩：
- 代码不解析 txt 里的标题，整个文件当一段字喂给模型；标题是给模型看的排版。
- 改了谁的人设，重启时 `--reset 谁 --seed`，否则旧信念会跟新人设一起喂给它、压过人设。
- 改人设也顺手看一眼 `seeds.json` 里它那几条还对不对。
